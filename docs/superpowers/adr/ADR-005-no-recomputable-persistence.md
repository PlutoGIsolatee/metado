# ADR-005：可重算数据不持久化

状态：已接受
日期：2026-09-22

背景：store 存什么。`signer_id`、`version`、`requested`、`entries` 等全部可从插件本体（原样 `.mdl`）重算，是否要在 state 中存镜像（含首装指纹锚）。

选项：
  - A：存镜像（含首装指纹锚），启动免拆包。
    优点：启动快，不拆包即可重建授权面。缺点：本体与镜像双源，drift 判定逻辑复杂；首装锚防的是同一可信域内的篡改，已被排除。
  - B：只存不可重算三样（决策事实 + 引用 + 状态），其余一律重算。
    优点：本体是唯一源，零 drift；store 最小。缺点：启动按需拆包（v1 不压缩、ZIP 索引 O(1)，开销可接受）。

决定：选 B。引擎是唯一写者、bundle 只能经引擎入位，首装锚冗余。

后果：同签判据改为与当前存储本体比对（主文档 §6.2-3 字面修订）；提速只能加"由本体哈希派生的缓存"，非契约。
